Financial Data Analytics Project

Does spending more buy more wins?

By Braden King

This project studies Major League Baseball team payroll and game-by-game success from 1985 through 2016. The data connects each team's season payroll to every regular-season game result, making it possible to test whether higher spending translated into more wins, stronger records, and better payroll efficiency.

Dataset Notes

The dataset combines Baseball Databank salary records with Retrosheet game and team-stat logs. One row in the cleaned file is one team in one game, with that team's full-season payroll attached to the row.

The processed file keeps AL and NL seasons from 1985 through 2016 because Baseball Databank salary coverage runs through those years. All-Star rows and team-code mismatches without payroll records are excluded.

Computed Fields

  • Season payroll = sum of listed player salaries for a team-season
  • Payroll rank = team payroll rank within that season
  • Payroll percentile = payroll rank converted to a 0-1 within-season scale
  • Run differential = team runs minus opponent runs
  • Winning percentage after game = wins to date / completed decisions to date
  • Cost per win to date = season payroll / wins to date
