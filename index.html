This project uses a player-team-season panel of Major League Baseball batting records from 1901 through 2021. The data shows a sport that shifted toward power, strikeouts, and specialized offensive value, while still preserving clear patterns by team, age, handedness, and player origin.

Dataset Notes

The dataset comes from Baseball Databank/Lahman-style CSV tables preserved in a public Baseball Databank mirror. The original tables used here are Batting, People, and Teams. One row in the cleaned file is one player on one team in one season stint. A player traded during a season can appear more than once for that year because each team stint is separate in the source table.

The processed file keeps AL and NL seasons from 1901 through 2021. Rows before 1901 and non-AL/NL league rows are dropped so the project focuses on modern Major League Baseball. Rate fields are calculated only when the denominator is positive.

Computed Fields

  • Plate appearances = at-bats + walks + hit by pitch + sacrifice flies + sacrifice hits
  • Total bases = hits + doubles + 2 * triples + 3 * home runs
  • Batting average = hits / at-bats
  • On-base percentage = (hits + walks + hit by pitch) / (at-bats + walks + hit by pitch + sacrifice flies)
  • Slugging percentage = total bases / at-bats
  • OPS = on-base percentage + slugging percentage
  • Isolated power = (total bases - hits) / at-bats
